# Phase 1 tables and tools

Made for `docs/RUST_PLAN.md` (Phase 1.1-1.3). Paths inside some tools still point at the machine they ran on; adjust before rerunning.

- `phase1-name-table.tsv`: one chosen name per ledger row, with provenance, confidence and proof. A name is a candidate, not proof of what a function does. Rows marked `withheld` had only an unlicensed or unknown-license source.
- `phase1-class-list.tsv`, `phase1-namespace-list.tsv`: class and namespace candidates from the demangled signatures.
- `phase1-actor-base-layout.md`, `.gate.txt`: the actor base chain's layouts and their check against the constructors in `main.dol`.
- `phase1-*.json`: summaries and the evidence verification.
- `tools/`: the scripts that made them, and `actor-base-layout.json`.

Left out on purpose: the evidence `.jsonl` files (about 37 MB, regenerated by the tools; they also cite an unlicensed source) and anything taken from the game disc.
